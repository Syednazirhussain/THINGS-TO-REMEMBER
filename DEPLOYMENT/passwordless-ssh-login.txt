Password-less SSH Login Setup (Complete Guide)
==============================================

Goal:
-----
Login to the server without being prompted for a password:
ssh root@165.245.189.135

✅ No password prompt
✅ More secure than passwords

How it works:
------------
- SSH uses public/private key cryptography
- Private key stays on your laptop
- Public key is stored on the server
- If keys match → access granted

Step 1: Verify SSH key exists (Local machine)
---------------------------------------------
ls ~/.ssh

- id_ed25519 → private key (keep secret)
- id_ed25519.pub → public key (safe to share)
- known_hosts → known server fingerprints

Step 2: Copy public key to server
---------------------------------
ssh-copy-id -p 22 root@165.245.189.135

Explanation:
- Connects to server using password (one last time)
- Appends public key to /root/.ssh/authorized_keys
- Sets correct permissions automatically

Step 3: Test password-less login
--------------------------------
ssh -p 22 root@165.245.189.135

Expected:
- Immediate login
- No password prompt

Step 4: Verify permissions on server
-----------------------------------
chmod 700 /root/.ssh
# Only root can read/write .ssh directory

chmod 600 /root/.ssh/authorized_keys
# Only root can read/write authorized_keys

Incorrect permissions can break key login

Step 5: Ensure SSH key authentication is enabled
------------------------------------------------
nano /etc/ssh/sshd_config

Add/verify:
PubkeyAuthentication yes
AuthorizedKeysFile .ssh/authorized_keys

Restart SSH:
systemctl restart ssh

Explanation:
- Enables public key authentication
- Defines where SSH looks for keys

Step 6 (Recommended): Disable password login
---------------------------------------------
⚠ Only after confirming key login works

nano /etc/ssh/sshd_config

Set:
PasswordAuthentication no
PermitRootLogin prohibit-password

Restart SSH:
systemctl restart ssh

Explanation:
- Disables password login
- Allows root login only via SSH keys

Final Result:
-------------
- SSH key-based login
- No password prompts
- Stronger security
- Faster access

Login command:
ssh root@165.245.189.135

Recovery Tip:
--------------
- Before closing your current session, test login in a new terminal
- Keep the session open to fix config if needed

Best Practices (Optional):
--------------------------
- Create non-root sudo user
- Change SSH port
- Enable Fail2Ban
- Restrict SSH by IP
