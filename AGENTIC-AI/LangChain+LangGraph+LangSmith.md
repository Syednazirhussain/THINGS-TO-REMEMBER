# LangChain
    LangChain is a framework that makes building LLM powered application easy.

    -   Usage: Used mainly to build straight-forword chains and retrival flows.
    -   Tutorial:https://www.youtube.com/watch?v=nAmC7SoVLd8

# Lang Graph
    Lang Graph is a framework to orchestrate multi-steps, stateful workflows using LLMs  with a graph based structure.

    -   Tutorial: https://www.youtube.com/watch?v=CnXdddeZ4tQ
